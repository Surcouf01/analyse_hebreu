# כתב « écrire » — conjugaison dans tous les binyanim

**כתב** (racine כ-ת-ב, verbe **fort** selon `classify_root` — aucune radicale faible) signifie « écrire ». C'est un excellent verbe de référence : régulier, il illustre la conjugaison type dans chaque binyan. Dans la BHSA (passages hébraïques), il est attesté à **223 reprises** sous forme verbale : **qal** (204), **nifal** (17), **piel** (2) ; s'y ajoutent 8 occurrences araméennes au **peal** (Esdre, Daniel). Les binyanim **pual**, **hithpael**, **hifil** et **hofal** ne sont pas attestés pour cette racine : leurs formes ci-dessous sont générées par le moteur du projet (`bhsa_grammar/binyan_gen.py`, gabarits du verbe fort) à titre théorique.

## Qal (קַל) — « écrire »

Le **qal** (קַל, « léger ») est le binyan de base, non dérivé : il exprime l'action simple, active ou stative. Pour כתב, c'est de très loin le binyan le plus fréquent (204 des 223 occurrences verbales hébraïques).

### Règles de formation

1. **Parfait (suffixe).** Le parfait qal de כתב suit le type A du verbe fort : כָּתַב, כָּתְבָה, כָּתַבְתָּ, כָּתַבְתִּי, כָּתְבוּ.
2. **Imparfait (préfixe).** יִכְתֹּב (3ᵉ m.), תִּכְתֹּב (3ᵉ f. et 2ᵉ m.), תִּכְתְּבִי (2ᵉ f.), אֶכְתֹּב (1ʳᵉ) — voyelle holam sur la 2ᵉ radicale.
3. **Wayyiqtol.** וַיִּכְתֹּב « et il écrivit » — waw conversif + pathah + daguesh dans le préfixe (28 occurrences attestées).
4. **Impératif.** כְּתֹּב « écris ! », כִּתְבִי, כִּתְבוּ, כָּתְבְנָה (17 occurrences attestées).
5. **Infinitifs.** Construit : כְּתֹּב (לִכְתֹּב « pour écrire ») ; absolu : כָּתוֹב.
6. **Participes.** Actif : כּוֹתֵב « scribe, celui qui écrit » ; passif qal : כָּתוּב « écrit » (113 occurrences du participe passif dans la BHSA — la formule « il est écrit » des citations législatives).

## Nifal (נִפְעַל) — « être écrit »

Le **nifal** exprime le passif simple ou le réfléchi ; pour כתב, « être écrit, être consigné » (17 occurrences). À l'imparfait et à l'impératif, le nifal prend un א prothétique : יִכָּתֵב.

### Règles de formation

1. **Parfait.** נִכְתַב « il a été écrit » — préfixe נִ + sheva sur la 1ʳᵉ radicale ; 3ᵉ f. נִכְתְּבָה, pl. נִכְתְּבוּ.
2. **Imparfait.** יִכָּתֵב (daguesh fort sur la 1ʳᵉ radicale après le préfixe, voyelle qamets-tsere) ; תִּכָּתֵב, אֵכָּתֵב (1ʳᵉ avec sere).
3. **Impératif et infinitif.** Impératif : הִכָּתֵב (ה prothétique + daguesh fort) ; infinitif construit : הִכָּתֵב.
4. **Participe.** נִכְתָּב « étant écrit » — נִ initial + qamets.

## Piel (פִּעֵל) — « écrire (intensif) »

Le **piel** exprime une action intensive, itérative ou déclarative ; pour כתב, « écrire (intensif) », « écrire longuement / à plusieurs reprises ». Il n'est attesté que 2 fois dans la BHSA pour כתב.

### Règles de formation

1. **Parfait.** כִּתַּב — sheva sur la 1ʳᵉ radicale, pathah + **daguesh fort** sur la 2ᵉ (תּ) : le redoublement caractéristique du piel.

3. **Impératif.** כַּתֵּב « écris ! (intensif) ».
4. **Infinitifs et participe.** Infinitif construit : כַּתֵּב ; participe : מְכַתֵּב « écrivant (intensivement) ».

## Le peal araméen

Dans les passages **araméens** de la Bible (Esdre, Daniel), כתב se conjugue au **peal** (équivalent araméen du qal, 8 occurrences verbales dans la BHSA) : כְּתַב, participe כָּתָב « scribe » (le fameux mot כְּתָבָא). Le moteur du projet ne génère pas les paradigmes araméens ; l'application les identifie via la langue (`languageISO = ar`).
